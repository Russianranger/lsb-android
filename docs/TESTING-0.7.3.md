# Beta 0.7.3: remove an old import after a verified PlayOnline update

Install the original-signed `LSB-Android-0.7.3.apk` (versionCode 77) over your current standard LSB app. Do not uninstall or clear data. Main and the published Beta 0.7 remain preserved. Installation removes nothing automatically. No client reimport, preparation, PlayOnline update, server rebuild or redeployment is needed.

The 0.7.2 comparison incorrectly blocked the old imported client because PlayOnline had updated the active preparation. Your support ZIP confirms a verified update with different FFXI DLLs, retained pre-update inventory, and a later loader replacement. The corrected check validates the active client independently and recognizes its recorded update ancestry. It accepts either the live update-verification receipt or the committed loader transaction's archived receipt, checking generation/session identity and unchanged updated binary hashes. A loader replacement can legitimately archive the original update receipt; it does not erase evidence for the game DLLs.

1. Keep your original ZIP or existing verified external complete backup. Stop the client and server.
2. Open **Manage backups and storage → Copies → Original imported client files → Remove imported files… → Verify and remove**. Updated game DLLs, ROM contents and obsolete original files may differ. A verified PlayOnline update related to this original can be removed without requiring byte-identical copies. The active prepared client, Windows/FEX environments, current USER/usr settings, connection and server/database remain untouched.
3. After success, refresh **App files** and check external `lsb/session/current`: the old `client` payload should be gone, while small settings/inventory/removal metadata and the **active prepared loader** remain. The supplied screenshot shows about **14.1 GiB** to reclaim. Android's own totals may update later. If cancelled after quarantine, finish **Copies → Interrupted backup removal**.
4. Launch normally, close and repeat Quick login. Verify your existing character and the same updated client. Start the existing server and check characters/accounts. Skip source rebuilding and another PlayOnline update for this cleanup test.

Unverified updates, altered active critical binaries, missing repaired ROM/0/0.dat, unrelated imports, pending/staged maintenance, damaged receipt history and symlinks still block removal. For a preparation without verified update history, the original full content comparison remains in use. Cleanup does not write to the prepared client or restore an older loader. Complete session/working-combination backups retain the updated prepared installation using the existing format; future imports can preserve prepared USER/usr settings. A fresh preparation or external launcher package still requires selecting a complete original ZIP again.
